# Outreach email footer

- `footer.html`: paste at the end of an HTML outreach email. Tables and inline styles only, so it renders in Gmail and Outlook. The logo is `public/email/logo.png`, served at https://sentriahq.dev/email/logo.png once this is deployed.
- `footer.txt`: the same footer for plain-text emails.

Before sending anything, replace `[REGISTERED ADDRESS]` in both files with the verified registered address. Have the opt-out wording checked by your legal reviewer if you write to prospects in the EU. When someone replies "remove", stop contacting them.
